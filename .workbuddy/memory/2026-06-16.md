# 2026-06-16 工作日志

## 跨场景关卡解锁动画触发方案（已修复切页/动画不触发 bug）
- DataSystem 新增 `pendingUnlockAnimLevelId` 字段跨场景传值。
- 新增 LevelUnlockTrigger.cs：挂到其他场景按钮上触发解锁+跳转。
- 新增 LevelSelectManager.cs：挂在关卡选择场景，用协程等两帧再切页+触发动画，解决 Start() 执行顺序和 Animator 激活时序问题。
- LevelUnlock.Start() 仅负责 RefreshLevelState()，跨场景逻辑已移出。
- RefreshLevelState() 不再控制 UnLocked/Locked 的 SetActive，避免动画播放前提前显示已解锁状态。
